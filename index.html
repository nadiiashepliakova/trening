Мета тренінгу

Навчитися перетворювати набір файлів на зрозумілий, структурований цифровий посібник, який зручно використовувати на уроках, систематично доповнювати й редагувати.

1 Порядок у файлах Єдина система назв і папок
2 Швидкий доступ Учні знаходять матеріали за лічені секунди
3 Готовий посібник Інтерактивний цифровий ресурс

  • Витрачаєте час на пошук необхідних матеріалів?

✅ Структурований цифровий посібник

Крок 1. Підготовка матеріалів

  • Знайдіть готову або створіть нову презентацію до уроку.
  • Збережіть її у форматі PDF.
  • У назві файлу не використовуйте пробіли! Дозволені лише дефіс або нижнє підкреслення.

    Наприклад: Інформаційні_війни.pdf

Крок 2. Реєстрація на GitHub

  • Перейдіть за покликанням GitHub та пройдіть процедуру реєстрації.
  • Натисніти «Continue with Google», щоб швидко зареєструватися через обліковий запис Google.
  • Введіть унікальне ім'я користувача. Це ім'я буде вашим публічним ідентифікатором на GitHub, тому рекомендується використовувати професійний варіант.
  • Завершіть процедуру реєстрації.

Крок 3. Початок роботи в GitHub: створення нового репозиторію

💡 Репозиторій на GitHub - це онлайн-сховище, своєрідна папка проєкту, де зберігається вихідний код, усі файли та історія змін.
  1. Увійдіть у свій акаунт на GitHub.
  2. Натисніть кнопку New repository.
  3. У полі Repository name введіть назву репозиторію.
    4. 💡 Назва репозиторію вводиться літерами ЛАТИНСЬКОГО алфавіту, дефіс або нижнє підкреслення замість пробілу!
    Наприклад: informatyka_10_klas
  4. Натисніть кнопку Create repository.

Крок 4. Створення папки в GitHub

  1. Відкрийте створений репозиторій
  2. Натисніть кнопку Creating a new file.
  3. У полі Name your file введіть назву папки літерами ЛАТИНСЬКОГО алфавіту та скісну риску.
    Наприклад: 10-klas/.
  4. У новому полі Name your file введіть назву файлу.
    Наприклад: blank.
    5. 💡 GitHub не дозволяє створювати порожні папки, тому цей порожній файл є своєрідною імітацією вмісту
  5. Натисніть кнопку Commit changes.
  6. Ще раз натисніть кнопку Commit changes.

Крок 5. Завантаження файлу

  1. Відкрийте створену папку
  2. Натисніть кнопку Upload files.
  3. Натисніть Choose your files.
  4. Оберіть файл презентації, яку ви зберегли у форматі PDF.
  5. Натисніть кнопку Commit changes.
  6. Ваш файл збережено у папку.

Крок 6. Створення цифрового посібника

💡Цифровий посібник — це сторінка зі змістом, де кожен розділ, тема або урок має своє посилання.

Базова структура сторінки зі змістом:

  • Заголовок — назва курсу або теми.
    Наприклад: «Інформатика. 10 клас. Основний рівень»).
  • Зміст — перелік розділів і уроків.
  • Посилання на файли — відкриваються в новій вкладці.

Приклад: сторінка-зміст

Так виглядає готовий цифровий посібник — файли відкриваються в новій вкладці.

  • Урок 1. Вступ до інформатики
  • Урок 2. Апаратне забезпечення
  • Практична робота №1

Крок 7. Створення сторінки змісту

  1. Відкрийте свій репозиторій на GitHub.
  2. Натисніть на Create new file
  3. У полі Name your fileвведіть назву index.html
  4. Натисніть кнопку Commit changes.
  5. Ще раз натисніть кнопку Commit changes.

Крок 8. Редагування сторінки змісту

  1. Скопіюйте надісланий код.
  2. Поверніться в репозиторій та відкрийте файл index.html.
  3. Оберіть в меню Edit file і вставте скопійований код.
  4. Натисніть кнопку Commit changes.
  5. Ще раз натисніть кнопку Commit changes.

Крок 9. Прикріплення файлу в зміст

  1. Відкрийте раніше створену папку 10-klas. Натистіть на PDF-файл і скопіюйте шлях до нього
  2. Поверніться в репозиторій та відкрийте файл index.html.
  3. Оберіть в меню Edit file і замініть шлях до файлу a href="files/urok-1.pdf" на скопійований.
  4. Натисніть кнопку Commit changes.
  5. Ще раз натисніть кнопку Commit changes.

Крок 10. Публікація цифрового посібника

  1. Оберіть із меню пункт Settings.
  2. Знайдіть і натиснітьPages.
  3. У розділі Branch змініть None на main
  4. НатистітьSave
  5. Зачекайти кілька хвилин, поки GitHub створить поклиння на сайт
  6. Натисніть Visit site
  7. Насолоджуйтесь результатом своєї роботи!
